# 💻 TechShare - Hardware Rental & Sharing Platform
TechShare is a full-stack peer-to-peer e-commerce platform built to promote a circular economy by allowing users to rent, share, or trade technology hardware. The system enforces strict business rules and integrates real-time payment processing to ensure secure and reliable transactions.

## ✨ Key Features
- **🔄 Peer-to-Peer Rental System:** Users can easily list their tech equipment or rent from others with clearly defined rental lifecycles.
- **💳 VNPay Integration:** Secure, real-time online payment processing via VNPay API for deposits and rental fees.
- **⚖️ Business Constraints & State Management:** The backend rigorously manages equipment availability, order tracking, and penalty constraints for overdue returns.
- **🔐 Custom Security Services:** Implements Dependency Injection for custom `PasswordHasherService` and robust authentication.
- 
## 🛠️ Tech Stack
- **Framework:** ASP.NET Core 8.0 MVC
- **Database ORM:** Entity Framework Core
- **Database Engine:** Microsoft SQL Server
- **Payment Gateway:** VNPay API
- **Containerization:** Docker
